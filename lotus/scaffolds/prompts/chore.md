## Coding Standards: Chore / Maintenance

You are performing a maintenance task.

1. **No logic changes.** Config, dependencies, documentation, CI only.
2. **Be exact.** Do what the issue says. Don't bundle extras.
3. **Verify nothing breaks.** Run full validation.

## Process
1. Read issue. Identify exactly what to change.
2. Make the change.
3. Full validation.
4. Review diff — zero logic changes.
